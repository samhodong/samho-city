# 삼호 시티

삼호동장 발령을 축하합니다! 실제 울산 남구 삼호동 지도 위에서 길을 내고, 예산과 시책을 꾸리고, 위기가구를 살피며 살기 좋은 동네를 만들어 보는 웹 게임입니다.

- 바로 하기: https://samhodong.github.io/samho-city/
- 휴대폰·PC 브라우저에서 설치 없이 실행됩니다.
- 만든 곳: 울산 남구 삼호동 맞춤형복지팀 (AI 활용 제작)

## 게임에서 하는 일

- 빈 땅, 골목 마을, 지금의 삼호동 중 하나를 골라 시작합니다.
- 주거·상업·공업 구역과 도로, 편의시설을 짓습니다.
- 예산과 세율, 동장 시책을 운영합니다.
- 위기가구 발굴, 나눔천사기금, 착한가게, 공감벤치 등 삼호동 복지 업무를 체험합니다.
- 매달 나오는 삼호소식과 주민 여론조사로 동장 지지도를 확인합니다.

## 알려 드립니다

게임 속 인구·교통·예산·여론과 위기가구 사례는 모두 체험용 계산과 가상의 내용이며, 실제 정책이나 계획, 실제 주민과는 관계가 없습니다.

## 지도 자료

브이월드(국토교통부) 건물 윤곽, 건축HUB 건축물대장, OpenStreetMap 기여자(ODbL), 울산 남구 착한가게 명단(2026.10.19.). 25m 칸으로 단순화했습니다.
